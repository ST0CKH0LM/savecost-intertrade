# Savecost Intertrade

Next.js redesign prototype for SaveCost Intertrade.

## Stack

- Next.js App Router
- TypeScript
- Global CSS
- lucide-react icons

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3001`.

- `/`
- `/about`
- `/products`
